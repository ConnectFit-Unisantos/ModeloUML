# Como abrir o projeto do Modelio

## 1. Copiar a pasta do projeto
Copie a pasta completa do projeto do Modelio.
Baixe o .rar e extraia a pasta connectfit

## 2. Instalar o Modelio
No outro computador:

1. Baixe o Modelio:
   https://www.modelio.org/

2. Instale normalmente

3. Preferencialmente utilize a mesma versão utilizada no projeto original

---

## 3. Localizar a workspace do Modelio
Após instalar, a workspace normalmente fica em:

```txt
C:\Users\SEU_USUARIO\Modelio\workspace
```

---

## 4. Colocar o projeto na workspace
Cole a pasta do projeto dentro da pasta `workspace`.

Exemplo:
```txt
C:\Users\SEU_USUARIO\Modelio\workspace\connectfit
```

---

## 5. Abrir o projeto
Abra o Modelio e siga os passos:

```txt
File → Open Project
```

Depois:
1. Selecione a pasta do projeto
2. Clique em abrir

---

## 6. Caso o projeto não apareça
Tente alterar a workspace:

```txt
File → Switch Workspace
```

Depois:
1. Selecione a pasta `workspace`
2. Reinicie o Modelio

---

## 7. Caso apareçam erros
Verifique:
- se a pasta foi copiada completa
- se a versão do Modelio é compatível
- se os módulos BPMN/UML estão instalados

---

## Observações importantes
- Não abra arquivos `.xmi` diretamente
- O `.xmi` serve apenas para exportação/importação de modelos
- Para preservar diagramas e layout, utilize sempre a pasta completa do projeto
- Evite renomear arquivos internos do projeto
- O projeto foi feito na versão 5.4.01 do Modelio
